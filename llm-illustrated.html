注意力九讲

大模型原理
图解讲义

"它是怎么知道'它'指的是猫而不是鱼的?"——答案只有一个词:注意力。先看不算数的全景:每个词对每个词"看一眼",看得越重,连线越粗。点一个词,看它的注意力都分给了谁。

序注意力之网 · 猫坐在鱼旁边,它在看谁?

这是示意权重(真实模型是每层每头的一组 softmax 数值,维度上千)。但要领全在这张网里:理解=动态地为上下文里的每个位置分配"谁与我有关"——RNN 靠传递记忆、CNN 靠局部窗口,Transformer 直接给每对位置拉一条专线,顺带把并行度解放了。

第 一 讲

Token 与向量:给文字找坐标

模型不认识字,只认识数。第一步 tokenize(BPE 类子词算法:高频成词、低频拆片,"图解讲义"可能是两个 token,"unbelievable" 拆成 un+believ+able),每个 token 查表得到一个可学习的向量(embedding,几百到几万维)——语义空间里,"猫"和"狗"是近邻,"猫"和"微服务"隔得远。但向量本身不含顺序信息,所以要位置编码补上"第几个"：老式正弦函数,现代主力 RoPE 旋转位置编码——把位置"旋进" Q/K 里,注意力分数天然感知相对距离,还便于外推到更长上下文(长文扩展的地基在这埋下)。

第 二 讲

Q·K·V:手算一次注意力

每个 token 用三套投影矩阵把自己的向量变出三个角色:Query(我在找什么)、Key(我是谁的线索)、Value(找到我后拿走什么信息)——像一场自带检索:每个词拿着 Q 去和所有词的 K 做点积打分(相关性),缩放(÷√d,防点积过大让 softmax 饱和)后过 softmax 变权重(总和 1),再用这组权重对所有 Value 加权求和——新向量就是"看完全场后的我"。三个矩阵 WQ/WK/WV 是学出来的:模型没被教过语法,它自己学会了"代词的 Q 会去找它的名词的 K"。这就是那行论文的全部家底:Attention(Q,K,V)=softmax(QKᵀ/√d)V。下一讲把多头、FFN、残差装进 Block。

图 24 词 ×2 维迷你版 · 每点一次进一步,数字全程可见

Query 来自"它",对四个词的 Key 打分→softmax→加权 Value。留意softmax 的指数放大:0.8 vs 0.2 的分差会被拉成悬殊的权重——注意力天生是" Winner-take-most "。

第 三 讲

Transformer Block:一条带旁路的装配线

把上一讲的注意力装进标准件:x → LayerNorm → 多头注意力 → 残差相加 → LayerNorm → 前馈网络 FFN → 残差相加 → 出。每件的家规:多头=把 d 维切成 96 个低维头各自看(有的头学语法、有的头学指代、有的头学位置——分工是涌现的);FFN=每个位置独立的两层 MLP,存"世界知识"的地方(参数量大头在这,注意力只占小头);残差=让"改写"变成"增量",梯度高速路保证百层可训;LayerNorm(前置)=稳定数值分布;再叠 N 层(32/80/126 层),"看一次不够,96 个头×N 层反复看"就是理解的全部机制。

第 四 讲

训练三部曲:先会说话,再说人话,再说好话

预训练=自监督的下一个 token 预测:拿几万亿词,目标函数朴素到极致——给前文预测下一词的最小化交叉熵。读遍互联网的它学会了语法、事实、风格(都是预测的副产品)。SFT=人类示范监督微调:几千到几十万条"指令→优质回答",教会它"对话的格式"——预训练模型会续写,不会"回答"。RLHF/DPO=偏好对齐:人类给两个回答分优劣,训练奖励模型(RLHF 用 RL 最大化奖励),或 DPO 跳过奖励模型直接从偏好对优化。同一个分布的三次变形:预训练后是"互联网的续写器",SFT 后是"听话的助手",对齐后是"懂分寸的助手"。灾难性遗忘靠混播预训练数据缓解,能力边界由底模决定——对齐是化妆,不是整容。

注意"首都是"之后:SFT 前它可能续写"卢浮宫开放时间"(语料里常同现)——不是不知道,是不知道你在问它;对齐后不仅概率给"巴黎",还学会了"不确定时说不确定"的分布形状。

第 五 讲

自回归解码:一个字一个字吐,和 KV Cache 的账

推理=循环:整段 prompt 并行过一遍网络(prefill,算力密集)→ 出首 token;之后每生成一词,把它接在后面再过一次(decode,访存密集)。没有 KV Cache 的话,每吐一个词都要重算整个前文的 K/V——O(n²) 的浪费;缓存历史 token 的 K/V(每层每头一份),新 token 只需算自己的 Q 去查全部 K——延迟从平方降到线性。代价:KV Cache 显存随序列长×层数×头维膨胀,长上下文+高并发时它比权重还吃显存——所以有了下一页的推理工程。

图 5生成"天青色等烟雨" · 看 KV 缓存一格一格垒起来
KV Cache(已算过的历史):

无缓存版每吐一词,前面所有词都要重新点亮一遍(每词的计算量与长度成正比,总平方);带缓存版每词只算自己——灰点变历史、金点是新格。温度/采样在第 6 册讲过,那是"抽哪个";这一讲是"抽一个词的工程成本"。

第 六 讲

显存墙:decode 为什么"算力闲着带宽忙"

算一笔账:70B 模型 FP16 权重 140GB;batch=1 的 decode 每生成一 token,要把140GB 权重全部读进计算单元一遍——用几次乘法就丢掉,H100 的算力利用率 5% 都不到,瓶颈全在"搬"。这就是内存墙,也是所有推理优化的出发点:连续批处理(continuous batching,把 batch 从 1 抬到几十,一次读权重服务更多 token——vLLM 的吞吐魔法本质是"摊薄"而非加速个体)、PagedAttention(KV 像 OS 分页管理,消灭碎片)、GQA/MQA(多头共享 K/V,缓存减到 1/8)、量化(FP16→INT8/INT4:权重搬运减半再减半)、投机解码(小草稿模型连猜几词,大模型一次验证——用"猜对"换"少读一遍权重")。推理优化没有玄学,全是在跟"搬 140GB"这笔账谈判。

第 七 讲

Scaling Law:把规模当成科学

Kaplan/Chinchilla 的核心发现:损失 L 与参数量 N、数据量 D、算力 C 近似幂律平滑下降——没有台阶,没有玄学,可以拿小实验外推大训练(工程预算的科学)。Chinchilla 修正:等算力下参数与数据要同步放大,当时的模型普遍"练得太少"——从此行业卷数据质量,4T/15T token 竞赛开场。"涌现能力"在平滑幂律上怎么看怎么像"分辨率错觉":评测是离散的(64%→92%),损失是连续的——规模不是魔法,是量变让"本来就会一点"变成"够用"。实践含义:想要更强的模型,先看数据配比与训练 token/参数比,最后才想架构花活。

第 八 讲

LoRA:微调的"补丁哲学"

全量微调 7B=动 70 亿参数、显存装优化器状态装不下。LoRA 的洞察:微调带来的"改动量"ΔW 其实低秩(学到的新知识在少数方向上)——于是冻住原权重 W,只训练 ΔW=B×A(d×r 和 r×d,r=8~64 远小于 d=4096)。参数量掉到 0.1%~1%,一个消费级显卡就能微调 7B;训练完 A×B 可以折进原权重(推理零开销),也可以热插拔(一底座多任务适配器)。它的兄弟谱系:QLoRA(4bit 底座+LoRA,单卡 33B)、Adapter/Prefix(更早的低秩尝试)、以及"提示工程≈用 prompt 当梯度"的对照面。大模型时代的定制不是重练,是打补丁。

第 九 讲(终)

全景图:三层世界各解各的题

收拢这册的坐标轴:训练层(预训练/SFT/对齐/LoRA——改变"模型是谁")→推理层(量化/批处理/KV 优化/投机解码——决定"跑得起多快多贵")→应用层(提示工程/RAG/工具/Agent 循环——决定"怎么为你所用",第 6 册全在这层)。三层的物理约束不同,别拿应用层的直觉去抬杠训练层的事实(比如"上下文窗口"属于模型架构与显存,"记忆"属于应用层设计——第 6 册的失忆问题在这里能找到根)。面试与选型都适用同一张地图:先定位问题在哪一层,再谈那一层的武器。

要点本册毕业标准:能给同事讲清"为什么 decode 快慢和参数量成正比而与算力无关"(第六讲)与"LoRA 为什么敢只训 1% 参数"(第八讲)。讲得清,大模型对你就不再是魔法了——和这套讲义从头到尾的信条一样:拆开看,都是工程。
